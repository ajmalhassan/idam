## Remaining owner steps

1. Review the landing page, real screenshots and privacy text; try the extension from the ZIP in your chosen browser.
2. Review and publish the draft GitHub release when ready. Submit the extension through the **Chrome Web Store**, the chosen primary distribution channel. The landing page and privacy policy are hosted on GitHub Pages. Keep the ZIP for development/testing. Once the listing is live, make its verified URL the landing page's primary installation link.
3. Recruit five consenting testers using the draft; collect day-one/day-seven observations. The template contains no invented people or feedback.
4. Resolve beta stop conditions before wider release. Complete manual installation/restart, assistive-technology and other-platform coverage where needed.
5. The developer account, HTTPS URLs and store assets are ready. The owner handles final store submission and publication.

The Vivaldi CSS theme is optional and distributed separately. These artifacts prepare the launch; they do not certify accessibility, publish anything or create an account/backend.
